## Тема

**Направление годового проекта:** интерпретируемое управление поведением LLM с помощью Sparse Autoencoders (SAE Steering).

**Итоговая тема:** «Название фичи против её реального действия». Изучаем, насколько описание фичи (например, «про извинения») совпадает с тем, что она делает при стиринге, и можно ли давать фичам названия по их действию.


## План работы

### 1. Подготовка — октябрь–ноябрь 2026

- Обзор литературы: SAE и Gemma Scope 2, построение меток фичей в Neuronpedia, стиринг через SAE и отбор фичей для стиринга.
- Окружение: Gemma 3 1B-IT и SAE из Gemma Scope 2, стиринг через хук на residual stream (добавление направления фичи с коэффициентом α), логирование экспериментов в MLflow / W&B.
- Выгрузка меток и статистик активаций фичей из Neuronpedia.
- Выбор слоёв и ширины SAE.
- Пилот на 20–30 фичах с понятными метками: подбор сетки α и проверка, что эффект стиринга виден.

**Результат:** пайплайн «фича → тексты при разных α» и зафиксированный протокол эксперимента.

### 2. Сбор данных — ноябрь–декабрь 2026

- Отбор 200–400 фичей со стратификацией по слою, частоте активации и типу метки (лексические, тематические, стилевые, поведенческие).
- Набор из 20–30 нейтральных промптов, разделённый на описательную и тестовую части.
- Калибровка α: 5–7 значений, включая отрицательные, в масштабе типичной активации фичи, чтобы сила стиринга была сравнима между фичами.
- Генерация текстов для всех фичей и значений α, а также текстов без стиринга; все генерации кэшируются.
- Метрики каждой генерации: сила эффекта (KL-дивергенция к распределению без стиринга) и связность текста (перплексия по модели без стиринга). По ним отмечаем инертные фичи и фичи, которые только ломают текст.

**Результат:** датасет генераций с метриками.

### 3. Стиринговые метки — январь 2027

- Промпт для LLM-описателя: на входе пары текстов «без стиринга / со стирингом» на описательных промптах при нескольких α, на выходе короткая метка — что меняется при усилении и при подавлении фичи. Метку из Neuronpedia описатель не видит.
- Отладка промпта на dev-наборе из ~30 фичей с ручной проверкой.
- Прогон на всей выборке.
- Проверка устойчивости: на подвыборке сравниваем метки разных описателей (Gemma 3 4B, 12B, API).

**Результат:** стиринговые метки для всех фичей.

### 4. Сравнение меток — февраль–март 2027

- Тест угадывания: LLM-судья получает метку и K текстов с тестовых промптов. Один текст получен стирингом этой фичи, остальные — стирингом других фичей со сравнимой силой эффекта, в том числе фичей с похожими метками. Случайный уровень — 1/K; судья и описатель — разные модели.
- Точность теста считаем отдельно для метки Neuronpedia и для стиринговой метки.
- Классы фичей: метка верна; метка обманчива (эффект есть, а с меткой Neuronpedia точность на уровне случайной); фича инертна; фича только ломает текст.
- Ручная разметка ~50 фичей всеми участниками: согласованность разметчиков (κ Флейса) и сверка с LLM-судьёй.
- Индикатор «сюрприза»: разница точностей стиринговой метки и метки Neuronpedia.
- Анализ зависимости доли обманчивых меток от слоя, частоты активации и типа метки.

**Результат:** доля фичей с обманчивыми метками и её разбивка по слоям, частоте активации и типам меток.

### 5. Выбор фичей — март–апрель 2027

- Набор из 20–30 целевых концептов и поведений (тема, тон, стиль ответа).
- Для каждой цели подбираем фичу по метке Neuronpedia и по стиринговой метке через поиск по эмбеддингам описаний. Бейзлайны — случайная фича и отбор по output score (Arad et al., 2025).
- Стиринг выбранными фичами и оценка LLM-судьёй: выраженность целевого концепта и связность текста.
- Сравнение доли успешных стирингов для разных способов выбора.

**Результат:** ответ, помогает ли стиринговая разметка выбирать фичи.

### 6. Плейграунд — апрель 2027

- Страница фичи: метка Neuronpedia и стиринговая метка рядом, индикатор «сюрприза», примеры текстов при разных α.
- Список фичей, отсортированный по индикатору «сюрприза».

**Результат:** демо в плейграунде.
