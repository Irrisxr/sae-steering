## Тема

**Направление годового проекта:** интерпретируемое управление поведением LLM с помощью Sparse Autoencoders (SAE Steering).

**Итоговая тема:** «Название фичи против её реального действия». Изучаем, насколько описание фичи (например, «про извинения») совпадает с тем, что она делает при стиринге, и можно ли давать фичам названия по их действию.


## План работы

### 1. Обзор литературы (EDA)

**Задача:** собрать обзор того, что сейчас существует по теме: на каких моделях и с какими декомпозициями делают стиринг, какими методами, на каких датасетах и бенчмарках его оценивают. По итогам обзора обосновать выбор модели, декомпозиции и метрик для следующих этапов.

- **Модели и их декомпозиции.** Какие модели используют для стиринга и какие для них есть открытые декомпозиции (SAE, транскодеры, кросскодеры): Gemma 2 и Gemma Scope, Gemma 3 и Gemma Scope 2, Gemma 4, Llama 3.1 и Llama Scope, GPT-2 и Pythia. Обоснование выбора модели для проекта.
- **Методы стиринга.** В чём идея основных подходов и чем они различаются:
  - *Направление из контрастных примеров* (ActAdd, CAA, ITI, RepE). Смысл направления задают сами данные: заранее понятно, какое поведение вытаскиваем, но под каждое поведение нужен свой набор примеров.
  - *Направление из декомпозиции* (стиринг фичами SAE). Направления уже готовы и данные не нужны, но смысл каждого задаёт автоматическая метка фичи. Если метка неточна, стиринг даёт не то, поэтому отдельно изучают, как отбирать фичи для стиринга.
- **Метки фичей.** Как строятся метки в Neuronpedia и других пайплайнах автоинтерпретации и как проверяют их качество.
- **Датасеты для оценки стиринга.** Датасеты под конкретные поведения: токсичность, отказы (refusal), тональность и др. Что в них лежит и чем оценивают результат.
- **Бенчмарки.** SAEBench, AxBench и их расширения (SynthSAEBench, Concept16K): что они меряют, как устроены внутри, по каким критериям и шкалам оценивают результат (рубрики LLM-судьи), откуда берут эталонные ответы (ground truth) и чем различаются между собой.
- **Метрики.** Какими метриками оценивают стиринг: entropy-based (KL-дивергенция, перплексия, faithfulness), атрибуция, поведенческие метрики и оценки LLM-судьи.

**Результат:** обзор литературы в отдельном файле [EDA.md](checkpoints/01-eda/EDA.md). Выбраны Gemma 3 1B-IT и SAE Gemma Scope 2 на residual stream, слои 7, 13, 17 и 22: у 99,6% их фичей есть метки Neuronpedia. Решения по стирингу и метрикам собраны в §7 обзора, ниже они разнесены по этапам.

### 2. Сбор данных — ноябрь–декабрь 2026

- Выгрузка из Neuronpedia меток, частот активации и максимальных активаций фичей.
- Пилот на 20–30 фичах с понятными метками: ширина SAE (16k, 65k или 262k), уровни KL, верхняя граница α и пороги поломки текста.
- Отбор 200–400 фичей со стратификацией по слою, частоте активации и типу метки (лексические, тематические, стилевые, поведенческие). Частые фичи, активные больше чем на 1% токенов, размечены хуже — учитываем это при отборе.
- Набор из 20–30 нейтральных промптов, разделённый на описательную и тестовую части.
- Стиринг: добавляем столбец декодера фичи в residual stream её слоя с α обоих знаков — для усиления и для подавления фичи.
- Сила стиринга задаётся уровнями KL к распределению без стиринга, чтобы фичи были сравнимы между собой: по три уровня на каждый знак α, стартовые — 0,5, 1 и 2. α для каждой фичи и знака подбираем в единицах её максимальной активации; фича, которая не достигает нижнего уровня при α до верхней границы, считается инертной.
- Генерация текстов для всех фичей на всех уровнях KL, а также текстов без стиринга; все генерации кэшируются.
- Метрики каждой генерации: KL-дивергенция к распределению без стиринга, перплексия (считает модель без стиринга, сравниваем с ответом без стиринга на том же промпте) и доля повторов. По ним отмечаем инертные фичи и фичи, которые только ломают текст.

**Результат:** датасет генераций с метриками.

### 3. Стиринговые метки — январь 2027

- Промпт для LLM-описателя: на входе пары текстов «без стиринга / со стирингом» на описательных промптах на нескольких уровнях KL, на выходе короткая метка — что меняется при усилении и при подавлении фичи. Метку из Neuronpedia описатель не видит.
- Стиринговую метку и метку Neuronpedia приводим к одному формату и длине, чтобы судья сравнивал смысл, а не подробность.
- Отладка промпта на dev-наборе из ~30 фичей с ручной проверкой.
- Прогон на всей выборке.
- Проверка устойчивости: на подвыборке сравниваем метки разных описателей (Gemma 3 4B, 12B, API).

**Результат:** стиринговые метки для всех фичей.

### 4. Сравнение меток — февраль–март 2027

- Тест угадывания: LLM-судья получает метку и K наборов генераций с тестовых промптов. Один набор получен стирингом этой фичи, остальные — стирингом других фичей при той же KL, в том числе фичей с похожими метками. Случайный уровень — 1/K.
- Точность теста считаем отдельно для метки Neuronpedia и для стиринговой метки.
- Дополнительная проверка без судьи — intervention score на тех же генерациях: насколько вероятнее становится метка для модели-оценщика после текста со стирингом, чем после текста без него.
- Судья и описатель — разные модели; варианты перемешиваем, температура 0. На подвыборке сверяем судью с более сильной моделью другого семейства (Claude или GPT) по каппе Коэна.
- Классы фичей: метка верна; метка обманчива (эффект есть, а с меткой Neuronpedia точность на уровне случайной); фича инертна; фича только ломает текст.
- Индикатор «сюрприза»: разница точностей стиринговой метки и метки Neuronpedia.
- Анализ зависимости доли обманчивых меток от слоя, частоты активации и типа метки.

**Результат:** доля фичей с обманчивыми метками и её разбивка по слоям, частоте активации и типам меток.

### 5. Выбор фичей — март–апрель 2027

- Набор из 20–30 целевых концептов и поведений (тема, тон, стиль ответа); для токсичности, отказов и тональности дополнительно берём датасеты из §4 обзора.
- Для каждой цели подбираем фичу по метке Neuronpedia и по стиринговой метке через поиск по эмбеддингам описаний. Бейзлайны — случайная фича и отбор по output score (Arad et al., 2025).
- Стиринг выбранными фичами и оценка LLM-судьёй по шкалам AxBench: concept (выраженность концепта), instruct (ответ по теме инструкции) и fluency (связность текста), итог — гармоническое среднее.
- Сравнение доли успешных стирингов для разных способов выбора.

**Результат:** ответ, помогает ли стиринговая разметка выбирать фичи.

- Список фичей, отсортированный по индикатору «сюрприза».
